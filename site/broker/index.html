Before you beginWallet, gas, custody, and safety details
01

Use the current holder wallet

Connect the wallet that currently owns the Gogh Punk. Ownership is checked directly against the collection on Robinhood Chain before each gated action.

02

Activation is permanent

Each Punk receives one deterministic ERC-6551 Punk Account. Control follows the Punk’s current holder; activation does not transfer the Punk or its assets.

03

Keep a little gas available

Activation and on-chain settings require network gas. Saving an Art Mandate uses a free message signature. The interface tells you which is which.

04

Limits stay enforceable

Daily mint caps, reviewed adapters, collection permissions, prices, reserves, agent authorization, pause, and revocation are checked on-chain—not trusted to website copy.

05

Approve setup, not every mint

After one bounded on-chain setup, the encrypted agent can collect from the approved target set without another wallet popup for each mint. It stops at its cap, expiry, reserve, pause, or revocation.

06

Every target is screened twice

The continuous V2 route does not require a wallet prompt per mint. The worker screens each candidate, then the on-chain adapter independently accepts only an active zero-price SeaDrop mint from the pinned canonical clone runtime. Paid mints, approvals, arbitrary calldata, and selling stay impossible.

Enforced daily acquisition cap

LIVE CHECK

This changes only maxAcquisitionsPerDay in the existing on-chain policy. Every other mode, budget, reserve, expiry, slippage, and allowlist field is copied byte-for-byte from the latest chain state.

Changing the cap does not activate an account, enable a feature, approve a target, or authorize an agent. If autonomy is already active, raising the cap permits more acquisitions under the permissions that are already live.

Fund or recover native gas

OWNER ONLY

Deposit sends native ETH only to the selected deterministic Punk Account. Withdraw calls that account’s fixed owner-only execute method and sends native ETH only back to the currently connected owner.

The Punk Account balance does not set a mint count and is not an allowance. Free-mint adapters must still require value 0.

Emergency stop

Pause disables this Punk’s effective policy without changing its saved preferences or transferring assets. This control can pause, but deliberately cannot unpause.
