Before you beginWallet, gas, custody, and safety details
01

Use the current holder wallet

Connect the wallet that currently owns the Gogh Punk. Ownership is checked directly against the collection on Robinhood Chain before each gated action.

02

Its NFT wallet is permanent

The first setup creates one deterministic ERC-6551 wallet for the selected Punk. Control follows the Punk’s current holder; setup does not transfer the Punk or its assets.

03

Know which wallet pays gas

Your connected owner wallet pays one-time setup transactions. The hosted automation agent pays later mint gas. The Punk Account receives NFTs and does not pay hosted-worker gas.

04

Limits stay enforceable

Daily mint caps, reviewed adapters, collection permissions, prices, reserves, agent authorization, pause, and revocation are checked on-chain—not trusted to website copy.

05

Approve setup, not every mint

After one bounded on-chain setup, the encrypted agent can collect from the approved target set without another wallet popup for each mint. It stops at its cap, expiry, reserve, pause, or revocation.

06

Every target is screened twice

The continuous route does not require a wallet prompt per mint. The worker screens each candidate, then the on-chain adapter independently accepts only an active zero-price SeaDrop mint from an exactly reviewed OpenSea Studio runtime. Paid mints, approvals, arbitrary calldata, and selling stay impossible.
