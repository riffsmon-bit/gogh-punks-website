2. One confirmation → directed paid mint

Selected owner test · #93 · Peppies World · historical-chain verification required

Mint one NFT from Peppies World for up to 0.0001 ETH.
  1. Send this in Talk. The Directed paid mint panel retains your maximum mint price and checks for a fresh quote for exactly one NFT. If historical chain verification is unavailable, it must explain the blocked state and request no new budget.
  2. Verify Peppies World: 0xb73f1d1aee57410d537d87b656e98b9d3df5b213. Check the mint price, fixed worker fee, total escrow, wallet network fee and expiry. The full quoted worker fee is charged only after successful delivery.
  3. Select Confirm mint budget in wallet and approve once. First use creates #93’s mint vault, so its network gas is higher than later authorizations.
  4. The worker checks every minute. A confirmed budget means funding succeeded; it does not mean a mint has been submitted. Use Recheck paid mint until delivery is verified. A second purchase signature should not be requested.
  5. Verify the receipt and NFT token ID. The destination is #93’s Agent wallet, 0xcadcfd37e715bc031cf0cec7fa2335091c878c83. Check Collection and Activity too; current NFT ownership is verified when Collection loads.

Historical contract reads and ownership logs must pass on both providers before a new budget can be confirmed. If history verification is unavailable, wait for the service to recover; no new budget should be requested.

If a review expires before any wallet request, cancel the unsent review and prepare a fresh quote. If a wallet request was made, recover its original transaction hash from wallet activity. Refreshing must not send it again. A failed recheck or invalid pasted hash should retain your typed recovery details.

If the mint stops or expires, review Mission cancellation, confirm it, then review Refund and withdraw. These are two separate wallet transactions. The refund contains unused mint escrow; network gas already spent is excluded.

3. Burn #1753 → teach #93 Rarity Eye

This permanently destroys #1753 and can remove access to its wallets, including assets received later. Its assets do not move to #93.

  1. Open Forge with #93 selected. Select Recheck selected test. Verify source #1753 and recipient #93.
  2. If shown, review and confirm Enable Forge. This administrator transaction unpauses the shared contracts for all owners while enabling only Rarity Eye research. Recheck its receipt.
  3. Review #1753 approval. If the review expired, select Cancel unsent review and prepare a fresh one. Approval does not burn the Punk or create a credit. Read the fresh wallet and obligation checks, and confirm the token-specific approval. Review any nonstandard assets and off-chain obligations before proceeding.
  4. Review Burn #1753 → credit #93. Check the owner acknowledgement, type BURN 1753, and confirm in the wallet.
  5. Verify the burn receipt and exactly one new training credit on #93. Then use Recheck training.
  6. Claim initial rarity slots if offered, learn Rarity Eye, and equip it. These are separate transactions. Training waits for chain finality between steps; recent observations were about 14 minutes. Recheck saved receipts while settlement is pending.
  7. Compare #93, #94 and #95. The result should identify that three-token sample and SAMPLE_ONLY. Unequip Rarity Eye and verify its equipped research action becomes unavailable; re-equip and repeat.

For the same saved review, failed checks retain your typed burn phrase and acknowledgement. A new or changed review resets both so you must confirm its current terms. An expired review stays disabled until you explicitly cancel it and request a fresh review.

5. Gas, ETH, WETH and NFTs

  • Agent gas: send “Fund gas.” Review the source, destination and a small amount you choose. Verify the balance change after the receipt.
  • V3 Punk Wallet ETH: open Fund. The V3 wallet balance is separate from Agent ETH and its EntryPoint gas deposit. Review the source and exact destination before signing.
  • WETH: use Fund → ETH ↔ WETH to wrap and unwrap a small chosen amount. Verify both balances. Wrapping does not place a bid.
  • NFTs: open Collection and check custody. Use the V3 recovery link for a V3-held NFT or Review Agent withdrawal for an NFT with verified Agent custody. The hero’s Acquisition history counts historical records; Collection shows currently verified holdings.

Open Fund → Agent owner recovery for #93. Select Agent ETH, EntryPoint gas deposit, ERC-721 or ERC-1155. Enter an exact amount or token identity, then choose Review recovery. Opening the panel or selecting a collection item must not request a transaction.

Before Confirm in wallet becomes available, review the Agent source, fixed current-owner destination, amount or token, maximum fee and expiry, then check the acknowledgement. Native withdrawals preserve the active mission reserve. EntryPoint withdrawal requires a confirmed recall while a mission is active. The owner wallet pays network fees.

If the wallet result is unresolved, use its original hash with Recover original transaction. A failed check retains the typed hash and pending state. Recheck saved receipt never resends; verified completion requires 12 confirmations. An expired unsent review must be cancelled and reviewed again. Keep browser recovery records while any request is unresolved.
