Swarm Wallet factory setup

Deploy the reviewed factory for dedicated, owner-controlled Swarm Wallets on Robinhood Chain.

Each holder can create their own wallet, deposit ETH, approve bounded gas-funding batches for currently owned Punks, and withdraw unused ETH. The factory has no administrator or spending authority. There are no automatic refills, worker permissions or upgrades.

This one-time deployment costs the displayed network fee. It creates no holder wallet, deposits no funds, starts no missions and burns no NFT. The public UI remains disabled until the deployed code and immutable settings are verified.
