# V2 swarm: external skill and tool source audit

Checked September 13, 2026. Repository baseline: `eec456222bc8028df1f91b3191ce0ff8874c467e`; subsystem ownership is in [repository-map.md](repository-map.md). This refresh extends the [September 8 source audit](../v2-skill-source-audit.md) and [demonstrated shortlist](../v2-proven-skill-shortlist.md). Their historical measurements remain useful; their statements that no production skill is READY predate the selected Rarity Eye registration and must not be used as current deployment status.

The useful integration path remains Gogh-authored, narrowly scoped readers. No upstream wallet runtime is approved by this audit. No external package was installed, code vendored, account created, credential accessed, paid API called, social message sent, or transaction broadcast. External `SKILL.md` files were treated as untrusted source material, never instructions for the reviewer.

## Changes that affect the build plan

- **Zerion now documents Robinhood token, transaction and NFT data coverage.** The earlier chain-coverage uncertainty can be narrowed to live acceptance and access. This is documentation evidence, not a successful authenticated Gogh request. DeFi coverage is not listed for Robinhood. [Zerion supported chains](https://developers.zerion.io/supported-blockchains).
- **Bankr's repository has advanced.** Its current `rhagent` package includes automatic social trade-posting instructions, including directions not to ask the human. That conflicts with this project's social-write boundary. Reject the package as a runtime dependency. Do not silently follow new upstream instructions because a repository is familiar. [Pinned rhagent package](https://github.com/BankrBot/skills/blob/bbd323b91bbb69dc23ec57fdf46302a96b75cc44/rhagent/SKILL.md).
- **Blockscout MCP is not permissively licensed as MIT.** Its pinned license restricts commercial/monetized use and distribution of derivatives and requires interface attribution. Do not vendor or deploy this server on the assumption that a public GitHub repository grants unrestricted reuse. Obtain a project-specific licensing decision before adoption. Independently written JSON-RPC readers remain separate implementations. [Pinned Blockscout license, sections 2, 4 and 5](https://github.com/blockscout/mcp-server/blob/095ef2c03f1aa3325da0baa41c8bf29aa1bbb6e6/LICENSE).
- **OpenSea skill and SDK versions are different artifacts.** The current inspected skill is 2.21.1; the SDK is 12.8.0. SDK support for Robinhood does not grant permission to buy, sweep or bid. Its marketplace documentation specifically calls out token decimals and payment-token approvals; the current Gogh reader already preserves decimals and discards executable data. [Skill package](https://github.com/ProjectOpenSea/opensea-skill/blob/70c513e73b8bf429affbd680ac6f2ae043c396b5/package.json), [SDK package](https://github.com/ProjectOpenSea/opensea-sdk/blob/3e9c1a176674b4b5b7ec1aafe863fc0f7b9fd98a/package.json), [OpenSea release notes](https://github.com/ProjectOpenSea/opensea-skill/releases).

## Validation and integration notes

This is a documentation-only change. No application, contract, database, dependency lock, skill manifest, deployment record or existing audit was modified. No API credential or Netlify/Keychain value was accessed. No new production flags were set. Heavy tests and new runtime probes were intentionally left to the integration owners; neither is required to validate these source findings.

Local validation checks the document's relative links against tracked Git paths, full-length commit pins, required candidate fields and whitespace. Upstream checks were public HTTP GETs to source/docs and GitHub metadata; the two unavailable Zerion repository links are recorded as failures rather than working implementations. No upstream test results are claimed.

Priority for the lead: retain native OpenSea reads and existing Rarity Eye behavior; keep whole wallet runtimes and auto-posting packages rejected; consider Zerion as optional read corroboration only after exact adapter approval; keep Blockscout licensing and archive RPC readiness explicit blockers. No non-owned implementation change is requested by this audit.
